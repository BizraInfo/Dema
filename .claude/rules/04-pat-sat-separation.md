# 04 — PAT/SAT separation

## Product (BIZRA/Dema runtime)

- **PAT** serves the operator's local mission.
- **SAT** serves truth, constitution, verification, integrity.
- PAT does not certify itself. SAT does not secretly execute user work.
- Dema presents results to the human.

Live PAT/SAT autonomy is **DESIGNED_NOT_LIVE** unless tests and reports prove otherwise.

## Claude Code (development environment)

`.claude/agents/pat-*` and `sat-*` are **implementation workers** for this repository.
They improve code quality; they are **not** the live Node0 PAT/SAT runtime.

Never conflate Claude subagents with measured product autonomy.

Dry-run surfaces: `closed-dual-loop-dry-run`, `dema realm council` (declared-only v0).
