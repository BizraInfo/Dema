# BIZRA ADK / Forge Boundary

ADK / Forge is build-time. It compiles a **Responsibility Package** and owns no runtime authority.

Inputs: human/product requirement, mission contract, topology, capability requirements, model/harness policy, verification contract, recovery contract, impact measurement plan.

Outputs: Mission Envelope, topology/capability manifests, wrapper manifests, FATE fragment, SAT contract, observer contract, mutation fixtures, recovery contract, lockfile, qualification descriptor.

Lifecycle:
DISCOVER -> CONTRACT -> COMPOSE -> RED -> BUILD -> TEST -> MUTATE -> QUALIFY -> CONTENT-ADDRESS -> SEAL -> PREVIEW

Runtime permission is separate.
