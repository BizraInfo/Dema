# BIZRA DEMA Startup Kit v0.1

**Status:** PROPOSED_DESIGN_SPECIFICATION  
**Authority:** ZERO — this kit does not grant runtime permission.

## Four distinct products
1. **BIZRA ADK / Forge** — build-time Responsibility engineering kit.
2. **BIZRA Harness** — runtime control shell around models/agents/tools.
3. **BIZRA Wrapper** — anti-corruption adapter around external capabilities.
4. **DEMA Startup Kit** — minimum system instruction + knowledge/policy/schema pack.

## Core invariant
> Compile responsibility, not autonomy.

A model may propose. A harness may orchestrate. A wrapper may translate. PAT may explore. SAT may verify. FATE may admit a bounded effect. Only the human sovereign originates purpose and consequential authority.

Do not inject the entire knowledge pack into every prompt. Load the minimum evidence-complete subset for the current mission.

This package is a design artifact, not runtime proof.
