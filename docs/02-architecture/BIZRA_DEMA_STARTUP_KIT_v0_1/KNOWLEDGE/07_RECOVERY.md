# Recovery
No recovery proof without a non-vacuity witness.

Pattern:
1. create unique mission/witness;
2. persist/seal it;
3. record lineage/authority;
4. kill predecessor process;
5. prove predecessor dead;
6. start fresh process;
7. recover from authoritative store;
8. verify same mission/contract/lineage;
9. re-check current admissibility;
10. prove no duplicate committed effect.

Default-before == default-after is not recovery.
