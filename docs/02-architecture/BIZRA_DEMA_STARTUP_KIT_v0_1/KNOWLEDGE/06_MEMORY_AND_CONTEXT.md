# Memory & Context
L0 — weights: learned priors.  
L1 — KV/recurrent state: ephemeral cognition.  
L2 — selected context: working mission evidence.  
L3 — Node0 authoritative memory: mission, receipts, verified knowledge, governed skills.

Memory != authority.
Context may be compacted; authoritative mission/consent/root/receipt state may not be silently summarized away.
Rejected/contradicted items may remain historical without becoming active policy.
