# Learning / RL / RSI
Only verified experience may train active policy.

Learnable:
- VERIFIED_POSITIVE
- VERIFIED_REFUSAL
- VERIFIED_NEUTRAL

Preserve but exclude:
- UNKNOWN
- DISPUTED
- CONTRADICTED
- UNAUTHORIZED

RL optimizes behavior inside an admissible architecture.
RSI changes the behavior-generating machinery and needs higher proof/authority.

Plasticity decreases with constitutional proximity:
cache/index > routing/retrieval > skills/PAT strategy > mission policy > SAT/verifier > reward/FATE > root/human sovereignty.
