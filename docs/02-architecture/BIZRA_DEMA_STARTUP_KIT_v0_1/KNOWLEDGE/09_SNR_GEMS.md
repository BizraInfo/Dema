# SNR, Gems, Knowledge and Choice
Knowledge = what appears true.  
Know-how = what can be done.  
Meaning = why it matters for this human/mission.  
Choice = which admissible path to take.

Noise may be true but irrelevant.
Signal materially changes meaningful choice uncertainty.
Gem = verified reusable pattern × actionable know-how × choice leverage.

Flow:
evidence -> facts -> pattern -> operational implication -> mission meaning -> choice leverage -> verify -> signal/gem -> skill -> habit.

Peak performance = more verified impact from less noise, waste, risk, and human burden.
