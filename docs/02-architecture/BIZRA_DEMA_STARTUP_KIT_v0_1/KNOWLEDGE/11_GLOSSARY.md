# Glossary
**ADK / Forge** — build-time Responsibility engineering kit.  
**Harness** — runtime control shell shaping model/agent capability.  
**Wrapper** — anti-corruption adapter around external components.  
**Mission Envelope** — durable mission identity/state contract.  
**FATE** — authority membrane.  
**PAT** — private proposer/cognition roles.  
**SAT** — independent verifier roles.  
**Receipt** — durable witness to a claim/transition/evidence set.  
**MR** — registry/resolution plane for qualified effective configuration.  
**VRO** — verified recurring responsibility with measured human/resource value.  
**Non-vacuity witness** — unique pre-failure state preventing empty-state recovery false positives.  
**Authority delta** — change in granted authority across a transition.
