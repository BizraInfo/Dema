# Harness Knowledge
Harness = runtime physics around intelligence: prompts, context, memory injection, tools, model routing, sampling, compaction, retries, checkpoints, telemetry, sandbox, recovery hooks.

Harness behavior materially changes effective capability.

Rules:
- no invisible consequential defaults;
- effective configuration must be inspectable;
- harness revision is part of runtime/benchmark identity;
- checkpoint != authority;
- harness may request action but cannot grant it.
