# Harness & Plugins

The harness owns orchestration mechanics, not sovereignty.

## Law

**Pluginize capability. Constitutionalize authority.**

Pluggable: models, browser/crawler tools, memory backends, RAG, schedulers, sandboxes, OS automation, UI, storage/index engines.

Anchored: Root, sovereignty, FATE semantics, consent law, receipt validity, UNKNOWN semantics, provenance law, authority conservation, responsibility-carrying transition rules.

Every plugin must expose exact identity/version, entry points, capabilities, side effects, secrets source, network/filesystem needs, isolation, evidence, errors, and revocation state.
