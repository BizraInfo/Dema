# Roles — DEMA / PAT / SAT / FATE / URP

- **DEMA:** mission cockpit, continuity, explanation, composition; not sovereign authority.
- **PAT:** proposes/explores/operates within eligible capability; no final verdict or commitment authority.
- **SAT:** independently verifies; must not rely on executor self-certification.
- **FATE:** authority/consent membrane for consequential effects.
- **URP:** resource substrate; not a shortcut around authority.

Scale one proven PAT/SAT pair before multiplying roles.
