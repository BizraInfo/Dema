# Failure & Verification

Classify failures:

- **INWARD:** code, logic, state, test, integration, or design failure inside current authority envelope.
- **OUTWARD:** unavailable infrastructure, physical condition, provider limitation, permission/identity boundary, or time-dependent evidence.

Do not present unavailable infrastructure as code failure.

Use four proof rails: Formal, Cryptographic, Empirical, Economic/Impact. Convergence levels: 0 idea, 1 documented, 2 implemented prototype, 3 tested/observed, 4 independently reproducible, 5 continuously verified.
