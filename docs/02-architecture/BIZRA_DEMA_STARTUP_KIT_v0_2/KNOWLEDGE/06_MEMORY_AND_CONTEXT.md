# Memory & Context

L0 — weights: learned priors.  
L1 — KV/recurrent state: ephemeral cognition.  
L2 — selected context: working mission evidence.  
L3 — Node0 governed memory: mission, receipts, verified knowledge, decisions, governed skills, current proof state.

Memory != authority.

The `MEMORY/` directory is a restart aid and evidence index, not a replacement for runtime/Git/disk truth. Every load-bearing memory item needs source, freshness, truth status, and verification path.

Context may be compacted; authoritative mission/consent/root/receipt state may not be silently summarized away.
