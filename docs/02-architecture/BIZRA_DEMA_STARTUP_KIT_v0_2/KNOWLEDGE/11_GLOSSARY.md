# Glossary

- **Authority:** permission to cause a bounded effect; not capability.
- **Canon:** state accepted as authoritative under its publication contract.
- **Capability cartridge:** replaceable external implementation satisfying a stable slot contract.
- **Decision Graph:** linked record of decisions, alternatives, evidence, consequences, and supersessions.
- **FATE:** authority/consent gate.
- **File Card:** provenance-bearing metadata record for one filesystem/source object.
- **Golden Set:** regression cases derived from verified decisions/failures/refusals.
- **ISNAD:** provenance/pedigree chain.
- **Knowledge Card:** source-bound claim/decision/procedure object with epistemic status.
- **PAT:** private agent team/operator role; proposes/acts within bounds.
- **SAT:** independent verification role.
- **UNKNOWN:** unresolved evidence state; never treated as PASS.
- **World adapter:** observer + actuator capability pair for a specific environment.
