# Learning / RL / RSI

Only verified experience may enter positive learning.

Learnable: VERIFIED_POSITIVE, VERIFIED_REFUSAL, VERIFIED_NEUTRAL.

Preserve but exclude: UNKNOWN, DISPUTED, CONTRADICTED, UNAUTHORIZED.

The learner must not unilaterally decide whether its own experience is reward-eligible. RL optimizes inside admissible architecture. RSI changes machinery and requires stronger independent proof, rollback/fork semantics, and explicit authority.
