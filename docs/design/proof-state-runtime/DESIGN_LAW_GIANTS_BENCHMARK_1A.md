# BIZRA design law — standing on giants, refusing the costume

Source: GIANTS-BENCHMARK-BIZRA-BOUNDARY-1A (2026-07-05). Binds every design produced in this project.

## The axis rotation (never design for a jury; design for the first user)
- Design 40% → **Proof density**: every pixel a claim that binds. No decorative anything.
- Usability 30% → **Consent clarity**: ease AND the byte-exact right to refuse. Friction where the constitution demands it.
- Creativity 20% → **Honest constraint**: interfaces incapable of overclaiming. Constraint made visible.
- Content 10% → **Evidence primary**: receipts ARE the content. `what_this_does_not_prove` is mandatory on evidence surfaces.

## ADOPT — the giants' craft floor (Awwwards SOTD anatomy, measured)
1. Custom everything — no template look, no AI-layout genericism; bespoke composition every time.
2. Motion as language, not garnish — scroll/state choreography that serves meaning; one motion per truth-event; spectacle rationed to the consent ceremony.
3. Typography as structure (the Adoratorio/Obys school): type IS the layout. House stack: Cinzel (engraved HUD/display caps) · Playfair Display (lore/editorial, italic for voice) · Inter (body) · JetBrains Mono (data, hashes, law).
4. Performance as design constraint — fast first paint, inline styles, zero heavy deps, no blocking assets. A 5s load kills a 10/10 visual.
5. Real content, integrated — never lorem ipsum; real hashes, real quest names, real receipts from the Dema repo. If data is a snapshot, label the snapshot date on-screen.
6. Small dense teams / craft density — N=1 extreme case: fewer, deeper artifacts.
7. Full developer-rubric axes: semantics · animations/transitions · accessibility (reduceMotion prop on every DC; contrast; hit targets ≥44px) · performance · responsive · clean markup.
8. Publish the instruments — keep components reusable, tweakable via props.

## DEEPEN — where they stop, BIZRA starts
- Refusal (∅), absence, and exit are first-class flows — a blocked action rendered as proudly as an executed one.
- Their award freezes at judging; our surfaces re-verify at every render — measured ≠ remembered.
- Their motion delights; ours testifies.

## REFUSE — never ship
Spectacle-first heroes · decorative motion or decorative hashes · engagement dark patterns · template velocity · emoji (not part of brand) · gradient-slop, rounded-corner-left-border-accent cards · award-chasing as a goal.

## House visual canon (established across Runtime Console / Realm / Mission Terminal)
- Ground: deep navy `#030810`→`#050B14`→panel `#071120`/`#0A1626` (radial, top-lit).
- Ink: parchment `#EDE6D3` line-work; gold `#C9A962`/`#EDD9A3` = live/emphasis; green `#5CE0A0` = verified/pass; amber `#D4B875` = designed/hold/preview; ember `#E0785C` = refused/failure/cursed (kept on display); violet `#B7A9F2` = attestation.
- Blueprint diagram language: 1px titled line-frames (label breaks the border), hatched dot-shadows (`radial-gradient` dots offset 8-9px), corner brackets on hero panels, dashed = designed-not-live, solid = shipped. Subtle scanlines + gold glow atmosphere, always gated by a `reduceMotion`/`--pl` var.
- Truth labels on every surface: PREVIEW_ONLY / SIMULATION_ONLY / MEASURED / DESIGNED_NOT_LIVE. Dashed elements get a `data-designed` attr and a fog/dim tweak.
- Consent is always an exact typed string that fails closed. Never a checkbox.
- Seed-of-life 7-circle mark = the only logo; never redraw a different one.

## The founding vision (MeMeLee · 2025-08-22) — six pillars, held to the law
The manifesto predates the law; the law disciplines it, never deletes it. Ship every pillar only in its lawful form:
1. Sacred geometry → structural, never ornamental: golden-ratio proportions, Fibonacci spacing steps (5·8·13·21·34·55), seed-of-life / Islamic circle lattices as quiet ground layers (circles only — no complex hand-drawn SVG). Geometry is the layout doing the proving.
2. Dynamic particles → particles are witnesses: they respond to presence (cursor parallax), stay within a strict density budget, and every one is gated by `reduceMotion`. Never confetti.
3. Revolutionary typography → the house stack IS the hierarchy; transformation is expressed through weight/scale shifts across the awakening arc, not novelty fonts.
4. Liquid motion → growth choreography: seed → root → forest as state transitions that testify (the world assembling around Dema), organic cubic-bezier easing, one motion per truth-event.
5. Consciousness-driven UX → the canonical arc, numbered on the HUD: 0 terminal (dark) → I awakening (first light) → II bond (covenant) → III revelation (the scan) → IV stewardship (home). Map every new surface onto this arc.
6. Color psychology → the canon palette already encodes it: navy depth (unknown) → gold (awakening/live) → parchment (knowledge) → green (verified). Enlightenment = verification, never brightness.
