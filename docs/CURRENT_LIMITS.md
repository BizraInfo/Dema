# Dema · Current Limits v0.1

The honest map of what Dema does today, what is designed but not live,
and what is planned. Read this before reading the README, before quoting
us in a slide, before recommending Dema to a friend.

The rule: **no surface in Dema may advertise a capability that the local
code does not actually implement**. If a feature is below "MEASURED"
truth level, this page names it.

> **Companion docs**:
>
> - [`BIZRA_NODE0_DEMA_GOAL_SCRIPT_v0_1.md`](BIZRA_NODE0_DEMA_GOAL_SCRIPT_v0_1.md) — the north-star goal this page tracks against. The goal names every subsystem; this page reports how much of each is `MEASURED` today.
> - [`ROADMAP.md`](ROADMAP.md) — what slices are moving rows on this page from `PLANNED` / `DESIGNED_NOT_LIVE` toward `MEASURED`.

> **Truth labels** used on this page:
>
> - `MEASURED` — verifiable from the local code or a captured artifact.
> - `DESIGNED_NOT_LIVE` — schema/spec exists, runtime does not.
> - `PLANNED` — design intent only; not in code yet.
> - `LOCAL_ONLY` — works locally but is not share-safe in its current form.

## Framework kernels (V2 set — deterministic validators, shipped #233–#238)

These five kernels are sometimes referred to collectively as a "reasoning
framework." That label oversells them. On disk each is a **deterministic
validator** — it performs no learned inference, no sampling, no text
generation, and no runtime execution. The `reasoner` / `HHMM` / `diffusion`
names describe the *shape* of a lifecycle/denoising metaphor, not a live ML
algorithm. Each kernel's own source header already states this; this table
lifts that disclaimer to the honesty map so the naming cannot mislead a reader
who only sees the README.

| Surface (truth label: MEASURED) | What it actually computes | Evidence |
| ------------------------------- | ------------------------- | -------- |
| HHMM lifecycle state machine (deterministic, NOT ML) | Infers a Node0/Dema lifecycle state from observable evidence via a fixed transition table + per-emission confidence constants. Header: "NOT machine learning, NOT learned probabilistic inference." | `packages/core/src/hhmm-state-machine.js` (lines 4–6, 51); `tests/hhmm-state-machine.test.js` |
| Hash-table knowledge index (6-axis, deterministic) | Indexes entries across 6 fixed axes (`HASH_TABLE_AXES`), requires an evidence anchor per entry, content-addressed `bucket_hash`. | `packages/core/src/hash-table-knowledge-index.js` (lines 5, 61–70); `tests/hash-table-knowledge-index.test.js` |
| Self-awareness report (blind-spot ledger, NOT consciousness) | Classifies each declared capability `EVIDENCED` / `BLIND_SPOT` / `NOT_KNOWN` by presence of an evidence anchor (`evidence.length > 0`). `claims_consciousness: false`; no introspection, model, or runtime. | `packages/core/src/self-awareness-report.js` (lines 6–12, 77–79); `tests/self-awareness-report.test.js` |
| Self-loop OODA cycle (bounded review, ACT cannot execute) | Orders + hash-binds 5 OODA phases (observe→orient→decide→act→review). `act_phase_must_not_execute`; `executed` forced false. NOT an autonomous loop, daemon, or scheduler. | `packages/core/src/self-loop-ooda.js` (lines 4, 92–101); `tests/self-loop-ooda.test.js` |
| Diffusion-reasoner (deterministic denoising-convergence, NOT a neural model) | `scoreDraftNoise` counts speculation/overclaim markers from a frozen lexicon; "convergence" = noise non-increasing toward an evidence-bound claim. Header: "NOT a neural diffusion model, NOT learned sampling, NOT stochastic, NOT generative." CLI: `dema diffusion refine` / `verify`. | `packages/core/src/diffusion-reasoner.js` (lines 18, 49, 73–84); `tests/diffusion-reasoner.test.js` + `tests/diffusion-cli.test.js` |
