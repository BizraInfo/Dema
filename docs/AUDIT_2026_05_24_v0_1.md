5. **Runtime-side behavior not invoked** — `dema status` · `dema first-run` · `dema model-broker` etc. verified by `npm test`'s 2,602 unit tests + per-PR CI, not by manual invocation.
6. **No static analysis beyond grep** — no cyclomatic complexity · no per-function metrics · no halstead. CodeQL provides this layer at CI.
