# docs/archive

Frozen, point-in-time session artifacts that are **not part of the live system
tree-map architecture**. Moved here so an agent reading the active `docs/` tree
follows the current architecture without being pulled into superseded plans,
dated specs, or historical audits.

**Selection criterion:** each file here had **zero inbound references** anywhere
in the repo at archive time (verified by basename grep). Archiving them therefore
broke no links — nothing pointed to them. They are kept (not deleted) as history.

**Do not treat anything here as current.** For live architecture, read
[`../INDEX.md`](../INDEX.md), [`../ARCHITECTURE.md`](../ARCHITECTURE.md),
[`../NODE0_MASTER_PLAN_v0_1.md`](../NODE0_MASTER_PLAN_v0_1.md), and
[`../NODE0_MASTER_CRAFTSMANSHIP_CHECKLIST.md`](../NODE0_MASTER_CRAFTSMANSHIP_CHECKLIST.md).

Relative links _inside_ archived docs may be stale (paths shifted by one level on
archival); this is expected for frozen records.
