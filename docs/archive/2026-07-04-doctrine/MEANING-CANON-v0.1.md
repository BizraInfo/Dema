## V · Tolerance Classes — the graduated gate

| Class | Definition | Gate | Receipt |
|---|---|---|---|
| **T · Trivial** | Reversible, zero external effect | Passes free | Lightweight log |
| **C · Consequential** | Creates or changes durable state | Intent card → one-word confirm | **Intent receipt** |
| **D · Dangerous** | Irreversible, external, economic, or lexicon-flagged | Byte-exact FATE phrase only | FATE receipt |

Class uncertainty → stricter class (Law 05). Class inflation without cause → Law 06 defect. The gate is graduated **so it never becomes friction theater** — trivial passes free, danger stays byte-exact, and the mirror lives only where it earns its cost.
